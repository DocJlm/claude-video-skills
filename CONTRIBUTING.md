# 贡献 / Contributing

欢迎通过 Issue 反馈可复现的问题，或通过 Pull Request 改进已有 skill。
添加新的原创风格时，请放在 `skills/<lowercase-hyphen-name>/`，包含：

- 带有 `name`、`description` 的 `SKILL.md`；
- 实际使用所需的工具、模板、环境要求和使用说明；
- 有权公开的效果示例，以及必要的署名与许可证；
- 可复现的验证方式，并同步更新中英文首页的已发布目录。

不提交密钥、个人配置、依赖目录、原始歌曲或未经许可的作品素材。
修改渲染器或工具后，请运行分镜检查和低分辨率渲染；提交时说明验证结果。

## English

Use issues for reproducible bugs and pull requests for improvements. New original
styles belong in `skills/<lowercase-hyphen-name>/`, with a `SKILL.md` containing
`name` and `description`, required tools and templates, setup instructions,
properly licensed examples, and a reproducible verification procedure. Update
both README catalogs. Do not commit credentials, personal configuration,
dependencies, original songs, or unauthorized media. Validate storyboards and
render a low-resolution sample after changing rendering code or tools.
