# 05 人物素材

字符画能不能看清，90% 取决于原图。原图规则：**纯黑背景 + 灰阶“石版画”质感 + 实心形体 + 强明暗分层**，人物不要有大面积纯黑（黑发、黑衣要画成带高光的深灰）。轮廓光剪影转成字符后只剩细线、人是空的，不要用。

## 一、先做定妆图
主角（和女主/第二主角）各一张：全身正面 / 侧面 / 背面 + 三个表情特写，16:9 一张图。后面所有动作帧都把它作为参考图，保证同一个人。

## 二、动作帧：一张图画 2×2 四格
**一次生成一张 2×2 四格**，比分四次生成一致得多（同机位、同人物、同背景），引擎自动切成 4 帧。

清单 `$P/assets/prompts/sheets.tsv`，每行用 Tab 分隔：
```
文件名	参考图（没有写 -）	画面描述（四格分别写 Panel 1..4 的动作）	类型(sheet|single|model)
```
例：
```
boat_row	assets/model_boatman.png	Medium side shot: the boatman rowing through a snowstorm... Panel 1: oar forward. Panel 2: pulling back hard. Panel 3: oar out of the water. Panel 4: braced against a big wave.	sheet
```
生成：`bash tools/gen_images.sh $P $P/assets/prompts/sheets.tsv`。脚本自动拼上 `templates/prompt_sheet.txt`（四格布局）和 `templates/prompt_style.txt`（灰阶石版画风格）。

### 写四格的诀窍
- 四格是**连续的关键姿态**：起势 → 动作 → 高点 → 收势/反应。比如敲键盘 → 停下 → 揉眼；起身 → 走 → 握门把 → 推门。
- 镜头、取景、背景四格必须一致，只有动作变。
- 情绪要夸张一点（大笑、击掌、仰头喊），字符化后细微表情会丢。
- 景别分配：全景用来交代场面，中景用于动作，特写（手、脸、道具）用于情绪高点。
- 需要配合 3D 人群（`crowd`）的四格：人群从背后看、占画面下半部分，四格分别是“放下手 / 举手 / 跳起 / 举着道具”。

### 一支 3–4 分钟的 MV 大约需要
定妆图 1–2 张 + 动作四格 15–25 组 + 单张场景若干。并行 4 张，codex 约 2–3 分钟一批。

## 三、验收（每张都要看）
- 是不是 2×2 四格、四格大小一致、没有边框数字（有边框会被切进画面）；
- 人物和定妆图是不是同一个人；
- 有没有大面积纯黑、文字、水印；
- 动作是不是一眼能看懂。
不合格的就删掉重新生成（脚本会跳过已存在的文件）。

## 四、没有生图工具 / 用户说“跳过”
1. **没有生图工具**：优先询问是否已有角色图片或动作帧。`gen_images.sh` 会把每张图的完整提示词打印出来。停下来，请用户用任意工具（ChatGPT、Midjourney、即梦、可灵、Codex 等）生成，按文件名放进 `$P/assets/frames/`，定妆图放 `$P/assets/`。
2. **用户明确选择“跳过人物” → 无人物降级版**：分镜里不用 `figure` / `montage` / `crowd` / `burst(人物)`，改用：
   - 叙事段：`words`（歌词大字）、`feed`（信息流）、`wordWave`（关键词墙）、`zoomSpark`（一颗火星里的词）、`code`（终端）；
   - 高潮段：优先用 `slam`、`wordWave` 与 `code` 强化排版节奏；`tunnel`、`spell`、`converge`、`stack` 仍为可选效果；
   - 爆发：`burst` 的 `asset` 换成 `{"text": "某个字"}` 素材，字炸成火星。

## 五、logo 与标志物
```bash
# 白底 logo → 深色背景可用版本（暗色字变浅色，彩色保留；彩色块里的深色图案改成背景色）
uv run --with pillow --with numpy --with scipy python tools/logo_dark.py logo.png $P/assets/logo_dark.png --keep-dark-in-color
# 汇聚用遮罩：白色形状黑底。彩色方块里镂空的图案，用 --keep dark 并裁到图标范围
uv run --with pillow --with numpy python tools/make_mask.py logo.png $P/assets/logo_mask.png --keep dark --crop 130,110,445,425
```
遮罩做好后先用 `stills` 渲染一帧汇聚锁定后的画面，确认形状认得出。
