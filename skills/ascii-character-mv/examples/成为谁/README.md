# 示例：《成为谁》（这套风格的诞生片）

AI Builder House（株洲人工智能创变者之家）的宣传 MV。3:48，140 BPM 恒速，男女对唱说唱 + 副歌。
本片是手写镜头代码做的（skill 的镜头库就是从这里提炼的），这里不附代码，只附**制作记录和两版方案**，用来学习：

- **风格从哪来**：参考 B 站《Hello, World》的字符画语法，加上“星火汇聚成簇”的意象。
- **叙事**：一个人（凌晨对着 AI、外卖凉了）→ 推门“冲破”→ 一群人 → 汇成那间房（logo）。主角加群像。
- **用户反馈改了什么**（`最终方案_v2.md`）：
  - logo 改成品牌绿；
  - “灯亮了”要先画出房子再亮窗；
  - logo 必须由火星汇聚，不能预先摆好；
  - 人物要真的动（于是有了 2×2 四格动作帧）；
  - 副歌整段进 3D。
- **最受好评的镜头**：副歌开场的火星隧道（We don't care who you were）。
- **衍生版本**：
  - 竖版高燃版：只去掉重复的副歌 2 和终段的 humming 循环；
  - 鸣谢版：打字声从“机器嗡嗡声”改成真人节奏。

重点读 `制作记录.md` 里的“踩坑”和“v2”两节。

> 本目录记录原片的制作选择。当前 skill 已调整为人物主导，原片中的星火和副歌 3D 方案不是所有新项目的必选规则。
