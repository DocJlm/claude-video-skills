# 字符星火 MV skill（ascii-ember-mv）

把任意一首歌做成“字符星火”风格的卡点 MV。

- **字符画人物**：一拍一动；
- **3D 字符火星**：爆散、隧道、人群、汇聚成标志物；
- **歌词**：逐字砸入；
- **终端 HUD 和卡点**：底鼓冲击、字符打散转场。

风格固定，内容随主题变：AI 社区宣传、古风单曲、毕业季、乐队、品牌发布都能用。

**给 agent 用**：让 agent 读 `SKILL.md`（Claude 系），或 `AGENTS.md`（Codex、Cursor 等），然后告诉它“用 ascii-ember-mv 给这首歌做 MV：<歌曲路径>”。

**给人看**：
- `docs/01-风格手册.md`：这个风格是什么；
- `examples/`：两支示例。

**环境**：macOS，Node 20+，ffmpeg，uv，python3。首次运行 `bash tools/doctor.sh`。

| 示例 | 主题 | 配色 | 说明 |
|---|---|---|---|
| `examples/成为谁/` | AI 社区宣传（说唱 + 副歌，140 BPM 恒速） | 余烬橙 | 完整 3:48 + 高燃剪辑版 + 鸣谢版的制作记录与设计取舍 |
| `examples/不系舟片段/` | 古风寒江（抒情，变速） | 寒夜渔火 + 楷体 | 用本 skill 从零做的 38 秒片段：分镜、生图清单、分析报告 |
