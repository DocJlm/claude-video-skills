# 《成为谁》MV · 修订方案 v2（2026-10-20，样片反馈后）

## 用户反馈（样片 v1）
- logo 要用绿色
- “灯亮了”看不懂
- “We don't care”火星隧道段很惊艳 → 作为全片高潮的基准
- 0:34 那一镜的 logo 不应预先存在，要由火星汇聚上去
- 人物、场景动画、动效、卡点都有很大提升空间；要带着批判的眼光不断完善

## 决定
1. **人物真的动**（选 A）：定妆参考图 + Codex 逐组生成 4–8 帧连续动作，按八分音符一拍一动
2. **logo**（选 A）：火星汇聚时由橙变绿，落定成品牌绿的屋顶和窗；其他强调色仍是余烬橙；片尾用真实 logo 图片
3. **3D 火星比例**（选 B）：副歌整段在 3D 火星空间（约 35%），主歌是会动的 2D 字符画人物
4. **卡点**（交给我判断）：加重（B）+ 动作卡拍（D）+ 快慢对比（E），歌词同步逐句复核（C）
5. **人物**（选 C）：主角（帽衫青年）串起开头 / 冲破 / 推门 / 就差你上场 / Bridge / 结尾；主歌 2 由女生领唱的群像，主歌 3 各行各业群像

## 自审问题清单（v1）
1. 人物全是静态图加慢推 → 动作帧
2. 转场只有硬切加逐行重绘 → 字符打散重组，踩小节线
3. 卡点只有底鼓缩放 → 字符密度跳变、镜头抖动、重音字放大、动作帧锁八分网格
4. “灯亮了”无语境 → 先画出房子，窗户落拍亮绿
5. logo 预先摆好 → 每次都由火星汇聚
6. logo 字标用的是等宽字体 → 片尾用真实 logo 图片
