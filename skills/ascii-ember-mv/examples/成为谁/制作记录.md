## 参考拆解
- 《Hello, World》：243 s，1920×1080，44 个镜头，three.js 逐帧渲染；全片字符画；深黑 / 米白两种底交替，一种橙色做强调；歌词是排版主体（大字 + 光标）；四角 HUD 标注每镜对应的模型部件；数据图表做隐喻（softmax 柱、注意力矩阵、上下文窗口）。偏克制，结尾回到终端 `print("hello, world")`。
- **要学的**：字符就是媒介；每镜一个具体隐喻并在角落标注；歌词是画面的一部分；一个强调色。
- **不学的**：它的克制节奏（本片要燃）；它的具体镜头和构图；“模型部件”这个题材。
- lemo ascii-crt 原生手法：画面由字组成、字号即镜头、推进一个字符发现它由更小的字组成、一次性的第二颜色。
- 花叔 05：转场落在节拍网格上；冲击缩放 1.03→1.0 与鼓点对齐；靠缩短镜头时长来加速。

## 定稿（2026-10-20）
方向 A「字符星火」为主体 + C「余烬星群」三维字符粒子只在高潮接管；片尾只放 logo + 中文名 + “我们在天元等你”；人名用虚构身份；只出横版中文 + 竖版中文；结尾不显影，回到终端。详见 `最终方案.md`。
**为什么这个题材选这个方向**：歌的弧线是“一个人 → 一群人”，字符画里每个字符天然就是一颗颗粒，“星火汇成簇”是这种媒介的原生动作；AI 社区与终端/代码亲近；又能保留参考片《Hello, World》的语法。

## 工程要点
- 速度 **140.00 BPM**，第一拍 0.236 s，小节线 = 0.236 + 1.7143·n（tools/tempo_fit.py 在全曲起音包络上搜索，漂移 ≤4 ms；librosa beat_track 给的 143.5 是错的）
- 歌词逐字时间：tools/align.py 按段落时间窗把正确歌词和 Whisper 字级时间做 difflib 对齐（全局对齐会因副歌重复而错位）
- 鼓点：tools/pattern.py 在八分网格上测低频/中高频冲击 → audio/grid.json；画面只在强拍做冲击
- logo 锁定在 46.52 s（小节线），“株洲人工智能创变者之家”按字级时间逐字打出
- 引擎：film/glyph.js（底片→字符网格）、core.js（网格/版式/歌词/HUD）、particles.js（three.js 字符粒子，图集 + 光晕两层叠加）、scenes.js（镜头表）、render.mjs（PNG→libx264，10 s 分段续跑）
- 人物素材：Codex 生成灰阶“石版画”式实心剪影（codex/gen.sh），实心比轮廓光剪影转字符好读得多；`codex exec` 要接 `< /dev/null`，否则会吃掉 while-read 循环的输入
- 540p 渲染约 85 fps

## 踩坑
- 反色闪（difference）会把橙色反成蓝色，和琥珀单色世界冲突 → 改为奶白闪光 3 帧衰减 + 军鼓轻提亮
- 句末标点取了下一个字的时间，导致“！”先于前面的字出现 → 标点取前一字时间
- 3D 粒子默认尺寸太小，像灰尘 → 点大小 ×2.5
- 竖版 logo 3D 镜头要单独拉远，否则越过顶部 260 安全线
- 本机 ffmpeg 没有 drawtext 滤镜

## 鸣谢页打字声（2026-10-20）
- tools/typing_sfx.py 按 CRED 逐字时间（每行起点 0.25 + 0.32·i 秒，每字 0.03 秒）合成机械键盘声：键帽触点（2.5–7 kHz 噪声）+ 触底低频 + 回弹；标题用重键，结尾一声回车，加极轻底噪 → audio/credits_typing.wav
- 混音：增益 +7.4 dB 后接 alimiter（limit 0.63），鸣谢段 -23 LUFS、峰值 -3.8 dBFS；整片 -14 LUFS、峰值 -1.9 dBFS（第一次没加限幅，峰值 +1.4 dBFS 削波）
- 更新：成为谁_竖版_中文_鸣谢版.mp4、成为谁_竖版_高燃版_鸣谢.mp4

## 鸣谢打字声 v2（用户反馈“死气沉沉不像打字”）
- 调研：Mechvibes / bucklespring / Thock 等多用真实录音（声音包授权不明，不用）；程序合成派如 Zylaxion：噪声激励 + 共振滤波 + 指数衰减；lemo ascii-crt：塑料咔 + 弹簧叮 + 键帽嗒，空格闷、回车重，人打字 120–150 ms/字并手工停顿
- v1 的问题：每 0.03 s 一下完全均匀（33 下/秒像机器）、每下音色一样、无按下/抬起、干声无空间、不区分按键
- v2（tools/typing_sfx2.py）：键间隔对数正态（中位 58 ms）+ 随机停顿 + 符号多停一下 + 每行回车；按下（触点 + 每键不同频率的键身共振 + 触底）+ 60–120 ms 后抬起；空格带平衡杆两下；回车更重；早期反射 + 80 ms 房间尾
- 声画同步：脚本同时输出 film/credits_schedule.json，scenes.js 鸣谢页按它逐字出现、光标跟随；鸣谢页 8.4 s（打字 6.9 s + 停留 1.5 s）
- 鸣谢段 -21 LUFS、峰值 -5.2 dBFS；成片 -14 LUFS
- 注意：Python 的 hash() 每次运行随机，合成里取值要用 ord()
