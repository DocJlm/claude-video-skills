# 示例：《不系舟》片段（用本 skill 从零制作的验收片）

- **歌**：古风抒情，约 76 BPM，**变速**（相位漂移 ±96 ms → 分析脚本自动改用 326 个真实拍点）
- **片段**：第 45–57 小节（2:24–3:02，约 38 秒）：Bridge → 主歌 3 → 终段副歌落拍
- **配色**：`ice` 寒夜渔火为底，品牌色改暖金 `#ffd98a`（江心那一点光是暖的）；歌词用楷体 `kai`
- **人物**：蓑衣渔人（先做定妆图 `model.tsv`，再出 3 组四格 `sheets.tsv`：风雪划桨 / 大江孤舟渔火 / 手心火光）
- **汇聚签名**：唱到“燃作江心一点光”时，渔人手心的火炸成火星（burst），再汇聚成楷体的“光”字，在唱到“光”时锁定变色；间奏再汇成“舟”
- **静默**：“既无岸”整句压暗，只剩“岸”字和光标（hold），下一句接爆发

## 叙事思路（为什么这样拍）
歌词的核心意象是“孤舟 + 一点光 + 千点渔火”。所以这一段的走向是：
1. 一个人逆风雪划船；
2. 既无岸（停住）；
3. 那就把自己点燃（爆散）→ 汇成一点光；
4. 春水来，回头看，千点渔火跟随（火星上升）；
5. 此去不回头（冲进火星隧道）。

和《成为谁》用的是同一套风格签名，但故事、配色、字体、汇聚对象全部不同。
