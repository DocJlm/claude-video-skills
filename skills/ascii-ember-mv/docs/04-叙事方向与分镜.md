# 04 叙事方向与分镜

## 一、先想叙事方向（给用户 2–3 个）
1. **从歌词里找核心**：这首歌最打动人的是什么？一个画面（江心一点光）、一个反差（一个人 → 一群人）、一个问题（你想成为谁）、一种情绪（不回头）。
2. **每个方向写清楚**：
   - 一句话创意；
   - 按段落的叙事（主歌讲什么、副歌爆什么、Bridge 怎么停）；
   - 人物设定；
   - 汇聚对象和汇聚时刻；
   - 配色；
   - 签名镜头（全片最记得住的一镜）；
   - 为什么适合这首歌。
3. **方向之间要真的不同**：叙事结构不同（单人旅程 / 群像接力 / 倒叙 / 一镜到底），不是同一个故事换配色。
4. 每个方向出 1–2 张关键帧，标出推荐。

## 二、storyboard.json 格式
下面的 `//` 只是说明，真实的 JSON 文件里不能写注释。
```jsonc
{
  "title": "片名（片头第一帧显示）",
  "range": ["bar:45", "bar:57"],          // 可选：只做一段时写；整首歌不写
  "palette": "ember",                      // 或 {"base": "ice", "brand": "#ffd98a"}
  "lyricFont": "sans",                     // sans | kai
  "accents": ["成为谁", "一点光"],          // 歌词里变色放大的词
  "logWords": ["build", "ship", "loop"],   // 背景滚动日志用词
  "hud": {"prompt": "~/builder-house $", "bl": "BUILDERS ONLINE: 1"},   // 或 false 关闭 HUD
  "converge": true,                        // 用户选择不用汇聚时写 false
  "assets": {
    "hero_typing": {"sheet": "assets/frames/hero_typing.png"},          // 2×2 四格动作帧（"grid": [2,2] 可改）
    "crowd":       {"sheet": "assets/frames/crowd.png", "fallback": "crowd_still"},
    "crowd_still": {"img": "assets/crowd.png"},                         // 单张图
    "logo_mask":   {"mask": "assets/logo_mask.png"},                    // 白色形状黑底：汇聚/垒起/点亮的目标
    "logo_full":   {"img": "assets/logo_dark.png"},                     // 深色底可用的真实 logo（片尾/汇聚后显示）
    "light":       {"text": "光"}                                       // 文字也能当汇聚目标
  },
  "shots": [ { "id": "s01", "type": "title", "t0": 0, "t1": "bar:7", ... }, ... ]
}
```

### 时间写法（`t0`、`t1`、`at`、`frames` 里都能用）
| 写法 | 含义 |
|---|---|
| `12.5` | 秒 |
| `"bar:12"` | 第 12 小节线（第 0 小节 = tempo.json 的 bar0） |
| `"bar:12+2"` / `"bar:12-0.5"` | 第 12 小节线后 2 拍 / 前半拍 |
| `"beat:96"` | 第 96 拍 |
| `"lyric:便将此身"` | 以这几个字开头的那句歌词的第一个字 |
| `"lyric:便将此身#4"` | 这句的第 5 个字（下标从 0 开始，标点不计） |
| `"lyric:且将寒江@2#0"` | 这句**第 2 次出现**时的第一个字（重复副歌用） |
| `"end"` | 歌曲结尾 |
| 任一写法 + `"~0.3"` | 再往后挪 0.3 秒（负数往前） |

### 镜头通用字段
| 字段 | 说明 |
|---|---|
| `id` `type` `t0` `t1` | 必填；镜头首尾相接，不能重叠也不能留空 |
| `lyric` | 歌词位置：`"top"` `"mid"` `"low"` `"left"` `"right"`，`false` 不显示；或 `{"pos":"mid","from":177,"upper":true,"size":96,"h":{...},"v":{...}}` |
| `cmd` `sec` `tag` `bl` | HUD 四角文字（或 `"hud": {"tl":..,"tr":..,"bl":..,"br":..}` 全自定义，`false` 关闭） |
| `flash` | 入场闪白（爆发瞬间用） |
| `noScr` | 不做字符打散转场（静默、3D 汇聚前后） |
| `hot` | 卡点冲击力度 0–1.2（默认按类型；静默 0、副歌 1） |
| `offbeat` | 故意不对拍（检查脚本不再提醒） |

## 三、19 种镜头类型
| 类型 | 用途 | 关键参数 |
|---|---|---|
| `title` | 片头：第一帧是片名，开场白以聊天记录逐条打出 | `title` `subtitle` `chat`(默认 true) `chatNames` |
| `figure` | 字符画人物/场景，主歌主力 | `asset` `frames`(`"beat"`/`"eighth"`/`"once"`/时间数组) `seq` `frame` `zoom`([起,止]) `fx` `fy` `dx` `cell`(字符大小，默认 8.5) `levels` `dim` `rise`(从某时刻起火星上升) |
| `montage` | 一拍一切的人物蒙太奇；可配每拍一个大字 | `items`([[素材,帧],...]) `words` `dim` |
| `words` | 纯歌词大字（日志滚动作底） | `bg`(`"none"` 去掉日志) |
| `contrast` | a 被划掉、b 砸进来（“不认命 / 只认真”） | `a` `b` `at` |
| `hold` | 静默：画面压暗，一个字 + 光标 | `char` `asset` `frame` |
| `burst` | 画面炸成 3D 火星（静默后的爆发） | `asset` `frame` `text` |
| `tunnel` | 火星隧道穿梭（副歌开场的王牌） | `speed` `roll` |
| `crowd` | 3D 人群，四格动作帧每拍换一个姿态 | `asset`(四格) `rows`(1–3 排纵深) `cam`{`z` `y` `look` `swing` `orbit` `roll`} |
| `converge` | **签名**：火星汇聚成标志物，锁定变品牌色 | `target` `from`(`"scatter"`/`"tube"`/人群素材) `at`(锁定时刻) `size`(7–10) `lift` `lookY` `lookYV` `brand`(false 不变色) `reveal`{`asset` `width` `y`}(锁定后显示真实 logo) `caption`{`lyric`或`text`}(逐字打出) `camZ` |
| `spell` | 火星拼成一个词 | `text` `font` `at` `size` |
| `stack` | 火星从下往上垒成标志物（“一起搭建”） | `target` `at` `label` `bar`(进度条，默认开) |
| `zoomSpark` | 推进一颗火星，发现它由一串词组成（“每一个你”） | `words` `glyph` |
| `wordWave` | 关键词墙 + 热浪扫过 | `words` |
| `feed` | 信息刷屏：聊天/弹幕/日志，每八分音符一条 | `items`([[谁,内容],...]) |
| `code` | 终端代码逐行打出 + 计数（结尾回到终端） | `lines` `hi`(高亮行) `counter`(`"LOOP × {n}"`) |
| `lightUp` | 标志物暗轮廓 → 到点亮起品牌色（“灯亮了”） | `target` `at` `width` |
| `slam` | 大字砸入（JOIN US!） | `text` `font`(mono/sans/kai) `at` |
| `glow` | 整屏被点亮 + 大字（“光芒！”） | `text` |
| `endCard` | 片尾：火星汇成标志物 → 真实 logo → 标语逐字打出 | `target` `logo` `tagline`(歌词开头) / `taglineText` `width` `widthV` `lookX` |
| `credits` | 鸣谢页（逐字 + 打字声，见 docs/07） | `lines` `schedule` `tag` |

## 四、节奏规则（照着排，片子就会“燃”）
1. **切镜落在小节线**（`bar:N`），歌词一般晚一拍进来；人物动作帧锁八分或一拍。
2. **剪辑密度递进**：主歌 1 两小节一切 → 主歌 2 一小节一切 → 快嘴段两拍一切 → 说唱/高潮一拍一切。
3. **副歌整段进 3D**：开场 `tunnel`（加 `flash`）→ `crowd` → `converge`（汇聚，在唱到主题词时锁定）→ `stack` / `slam`。
4. **至少一次静默**：Bridge 或爆发前用 `hold`（`hot` 0），之后接 `burst` / `tunnel` 并加 `flash`。
5. **汇聚至少一次在副歌、一次在片尾**；锁定时刻对准歌词里的主题词（`at: "lyric:...#k"`）。
6. **重复的段落要换讲法**：第二遍副歌换镜头组合、换视角（俯拍人群、更快的隧道），不要原样重复。
7. **每个镜头必须有一个具体的物**（人、道具、标志物、词），不能只有空背景。

## 五、写完的检查
```bash
python3 tools/check_storyboard.py $P
```
它会查：类型、必填参数、素材是否存在、时间能否解析、镜头之间的重叠和空缺、起点是否在拍点上、有没有 3D 镜头、有没有汇聚签名。
