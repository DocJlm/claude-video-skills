# 02 需求访谈

## 规则
- **一次只问一个问题**。给 2–4 个选项（A/B/C/D），把推荐项放第一个并写“（推荐）”，最后一个可以是“其他”。
- 根据回答决定下一个问题；用户说“你决定”时，自己按风格手册选最合适的，并说明理由。
- 用户的答案有歧义（比如署名、拼写、谁是谁）时**必须追问确认**，尤其是要印在画面上的文字。
- 问完把答案整理进 `$P/brief.md`，在制作记录里注明“需求已确认”。

## 问题清单（按顺序，已知的就跳过）
1. **歌和歌词在哪？** 要 mp3/wav + 歌词文本。歌词里没有 `[段落]` 标签的话，你来按结构补上（Verse/Pre-Chorus/Chorus/Bridge/Outro）。
2. **这支 MV 拿来做什么、在哪放？** 宣传招募 / 活动大屏 / 单曲发布 / 纪念……决定横竖版优先级和是否要剪辑版。
3. **配色**：给出最适合主题的 1–2 个预设和理由，也允许自定义。
4. **汇聚签名**：用不用？汇聚成什么（logo / 片名 / 一个字 / 主题符号 / 一个人）？有 logo 就要原图。
5. **人物**：主角 + 群像（推荐，有情感线又有广度）/ 只有群像 / 无人物（纯字符与火星）。有主角时问外形设定（年龄、性别、穿着、标志性道具）。
6. **片尾**：只放标志物 + 一句话，还是要地址、二维码等信息。
7. **版本**：横版 / 竖版 / 剪辑版（高燃、约 60–90 秒）/ 鸣谢版。默认横版 + 竖版。
8. **鸣谢内容**（要鸣谢版时）：逐行写出“职位 + 名字”，名字的拼写、要不要标注平台名（如“视频号”）逐一确认。

## 选项写法示例
> **这支 MV 的“汇聚”高潮要汇成什么？**
> - A. 你们的 logo（推荐）：火星在副歌落拍时汇成 logo 图形，锁定瞬间变成品牌色
> - B. 片名大字“XXX”
> - C. 一个主题符号（比如学士帽），我来做图形
> - D. 不用汇聚
