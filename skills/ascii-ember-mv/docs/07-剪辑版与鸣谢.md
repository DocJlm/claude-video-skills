# 07 剪辑版与鸣谢

## 一、剪辑版（高燃版 / 短版）
从**带声音的完整成片**按原片时间段剪接，画面不用重渲。

```bash
python3 tools/recut.py $P $P/成片/<片名>_竖版.mp4 $P/cut.json <片名>_竖版_高燃版
```
`cut.json`：
```json
{ "segments": [[8.38, 113.38], [137.38, 195.66], [212.81, 228.45]],
  "video_segments": [[8.38, 113.38], [137.38, 195.46], [212.61, 228.45]] }
```

### 先问清楚
- 目标时长（60 秒 / 90 秒 / 只去重复）。
- 开头从哪里开始：从第一句有记忆点的歌词？用冷开场钩子（先放 2 秒最炸的画面）？
- 用户说“只去掉重复”时：**只剪重复的副歌和尾段循环，不重复的段落一律保留**。

### 选剪点的规则
1. 剪点落在**小节线**上；前后两段的小节相位一致（都在第 1 拍）。
2. 剪点前后 0.3 秒内**没有唱到一半的字**：从 `lyrics.json` 找上一句最后一个字之后、下一句第一个字之前的空隙。
3. 重复段落保留**最燃的那一遍**（通常是升调的终段副歌）。
4. 原曲在高潮前常有半拍的空白，接在它前面会形成“急停 → 爆发”，是好剪点。
5. **画面剪点可以和音频不同**：被剪掉的镜头可能在接缝处闪 0.1–0.2 秒（比如一团粒子的开头几帧）。这时把 `video_segments` 的剪点前后挪开，避开残帧，保持每段长度和音频一致。
6. 剪完看脚本打印的接缝音量：前后差 8 dB 以上要去听；再抽接缝前后的帧条看画面。

## 二、鸣谢页
### 1）在分镜里加一个 credits 镜头（放在歌曲结束后）
```json
{ "id": "thanks", "type": "credits", "t0": "end", "t1": "end~6",
  "lines": [["title", "鸣谢"], ["role", "// 出品"], ["name", "张三 & 李四"], ["role", "// 作词"], ["name", "王五", "（副标题小字）"]],
  "schedule": "analysis/credits_thanks.json", "tag": "视频号", "hud": {"tl": "~/xxx $ cat CREDITS"} }
```
- `lines`：`title` 大标题，`role` 职位（建议以 `// ` 开头，终端注释风格），`name` 名字（第三项是可选的小字副标题）。
- `tag`：每个名字打完后出现的小标签（比如都是视频号名称时写 `"视频号"`），不需要就不写。
- 可以写多个 credits 镜头（不同版本不同鸣谢），渲染时用 `--q credits=<id>` 选一个。

### 2）生成打字声 + 逐字时间表（声画同步）
```bash
uv run --python 3.12 --with numpy --with scipy --with soundfile python tools/typing_sfx.py $P thanks [--hold 2.0]
```
真人打字节奏：
- 键间隔约 58 ms，随机浮动，敲符号前会多停一下，偶尔停顿，每行结束敲回车；
- 每一键 = 按下（触点 + 键身共振 + 触底）+ 抬起；空格更闷，回车更重；
- 加了短房间混响。

页面时长 = 打字时长 + 停留（名字少于 6 行停 2.5 s，否则 1.5 s）。

### 3）渲染鸣谢片段并拼进成片
```bash
E=$(python3 -c "import json;print(json.load(open('$P/analysis/tempo.json'))['duration'])")
node engine/render.mjs $P video --t0 $E --t1 credits --w 1080 --h 1920 --name cred --q credits=thanks
python3 tools/deliver.py $P $P/out/final_1080x1920.mp4 <片名>_竖版_鸣谢版 --credits $P/out/cred_1080x1920.mp4 --typing $P/analysis/credits_thanks.wav
```
打字声自动调到约 -21 LUFS（比歌轻），加限幅防止破音。
### 注意
- 鸣谢页上的每个名字都要和用户逐字确认（拼写、要不要加书名号、`&` 还是“和”）。
- 横版、竖版的鸣谢内容可以不同，各用一个 credits 镜头。
