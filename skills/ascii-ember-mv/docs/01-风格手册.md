# 01 风格手册：什么是“字符星火”

**一句话**：整个世界由字符组成；每个字符是一颗火星；成千上万颗火星在鼓点上爆散、穿梭、汇聚。

这个风格最初为《成为谁》（AI 社区宣传 MV）设计，核心意象是“点点星火汇聚成簇”。换任何主题时，**风格签名保留，内容全部重新设计**。

## 一、固定签名（每支片都要有）

| 签名 | 具体做法 | 引擎里对应 |
|---|---|---|
| 字符画人物与场景 | 灰阶插画 → 按亮度换成字符（`.:-=+*o%#@`），人物用 2×2 四格动作帧，**八分音符或一拍一动** | `figure`、`montage` |
| 3D 字符火星 | 每颗粒子是一个发光字符；爆散、隧道穿梭、人群跺脚、汇聚成形 | `burst`、`tunnel`、`crowd`、`converge`、`spell`、`stack` |
| 歌词是排版主体 | 逐字按演唱时间砸入（放大 → 回落），重音词用强调色、放得更大；光标跟着字走 | 所有镜头的 `lyric` |
| 终端 HUD | 四角小字：左上命令行、右上段落名、左下计数、右下镜头标签 | 顶层 `hud` + 镜头 `cmd`/`sec`/`tag` |
| 卡点语法 | 底鼓 → 画面冲击缩放 + 字符变亮 + 轻微抖动；切镜踩小节线；切点前后字符打散再聚拢；入场闪白 3 帧衰减 | 引擎自动（镜头 `hot` 控制力度） |
| 段落反差 | **主歌 = 2D 字符画讲故事；副歌 = 整段进 3D 火星空间** | 分镜规则 |
| 静默 | 全片至少一次真正的停顿（压暗 + 一个字 + 光标），停顿后接最大的爆发 | `hold` → `burst`/`tunnel` |
| 片头片尾 | 第一帧就是片名（不先黑场）；结尾回到终端/光标收束 | `title`、`endCard`、`code` |

## 二、汇聚签名（默认有，用户可选不用）

“散落的火星汇聚成一个标志物，锁定瞬间由火星色变成品牌色”。汇聚对象在需求访谈里问：
- 品牌 logo（用 `tools/make_mask.py` 做白色遮罩）
- 片名或一个字（`{"text": "光"}`）
- 主题符号（校徽、学士帽、乐队标志……做成遮罩图）
- 人物的一个动作帧（从人群里升起火星汇成一个人）

用户选“不用”时，在 storyboard 顶层写 `"converge": false`，检查脚本就不再提醒。

## 三、可变部分（随主题换）

### 配色预设（storyboard 顶层 `"palette"`）
| 名称 | 气质 | bg 底 | accent 火星 | brand 汇聚后 |
|---|---|---|---|---|
| `ember` 余烬橙（默认） | 科技、热血、夜里的创造者 | #0b0907 | #ff7a2f | #a6cf4f |
| `ice` 寒夜渔火 | 古风、孤独、雪夜、远方 | #04070c | #ffb35c | #9fd8ff |
| `neon` 霓虹青 | 电子、赛博、夜店、游戏 | #05060a | #19e3ff | #ff3ea5 |
| `gold` 鎏金 | 庆典、颁奖、品牌高光 | #0a0805 | #f2b23a | #ffffff |
| `sakura` 樱粉 | 青春、毕业、恋爱、春天 | #0b0709 | #ff6f9a | #9be37a |

自定义：`"palette": {"base": "ice", "brand": "#ffd98a"}`（以某个预设为底，只改几个色）。可改的键：`bg ink mid dim accent accentHi brand`。

**配色原则**：
- 全片只有一种强调色（火星），品牌色只在汇聚锁定、品牌出现时用，不要到处撒；
- 底色永远是近黑；
- 不要从 logo 直接取背景色。

### 其他可变项
- **歌词字体** `"lyricFont"`：`"sans"`（思源黑体粗，默认，现代/热血）或 `"kai"`（霞鹜文楷，古风/抒情）。
- **HUD 文案**：顶层 `"hud": {"prompt": "~/class-of-2026 $", "bl": "同学 × 1"}`，镜头里 `cmd`（命令）、`sec`（段落）、`tag`（如 `"渔火 / LANTERNS"`）、`bl`（计数随剧情增长）。HUD 不一定是代码：毕业季可以是 `~/class-of-2026 $ ./graduate`，古风可以是 `~/寒江 $ ./row`。
- **背景滚动日志的词** `"logWords"`：按主题换。
- **重音词** `"accents"`：歌词里要变色放大的词。
- **人物**：主角 + 群像 / 只有群像 / 无人物。

## 四、做坏的方式（交付前对照）
1. **每镜同一个动作**（全是慢推）→ 推、拉、横移、硬切、3D 穿梭要轮换。
2. **3D 粒子太小像灰尘** → 汇聚目标 `size` 7–10，镜头别太远。
3. **人物是死的**（静态图慢推）→ 必须用四格动作帧，帧切换锁在拍点上。
4. **标志物预先摆好** → 必须从散落的火星汇聚而来。
5. **竖版是横版裁的** → 竖版原生构图，引擎已自动重排，但要叠安全区审一遍。
6. **燃不起来**：底鼓没有冲击、副歌没进 3D、没有静默对比、剪切太慢。
7. **一眼 AI 味**：蓝紫渐变、霓虹满屏 → 遵守单一强调色。
