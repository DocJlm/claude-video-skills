# 《成为谁》MV · 最终方案（2026-10-20 定稿）

## 定了的事
- **方向**：A「字符星火」为主体，C「余烬星群」作为高潮武器，只在最燃的几个时刻接管
- **片尾**：只放 logo + “株洲人工智能创变者之家” + “我们在天元等你”；不放地址或二维码
- **人名镜头**：用虚构的身份描述（各个行当），不涉及真实个人
- **版本**：横版中文 1920×1080 + 竖版中文 1080×1920，各自原生构图，完整 3:48，30fps，-14 LUFS，歌词嵌在画面里，另附 `.srt`
- **结尾**：不显影成彩色插画，全片保持字符画；回到开场那个终端，首尾呼应

## 视觉规则
- 暖黑底 `#0b0907`，米白字符，余烬橙 `#ff7a2f` 是唯一强调色；**logo 绿只给 House 的那扇窗**，0:44 第一次亮起，之后不随意使用
- 字体：JetBrains Mono（字符画、HUD），Noto Sans SC 900（歌词大字），都是 OFL 许可
- 人物和场景：Codex 生成灰阶实心剪影（lithograph 质感，前景亮、后景暗），代码转成字符画；不直接出现插画
- 四角 HUD：左上终端命令，右上段落和时间，左下 `BUILDERS ONLINE` 计数，右下 `[ 中文 / ENGLISH ]` 镜头标签（学参考片，但标注的是 builder 的状态，不是模型部件）
- “字号即镜头”：推近就是字符变大，拉远就是字符变小、列数变多
- **C 模式（3D 字符粒子）**：字符脱离网格，在 three.js 三维空间里发光飞行，镜头穿梭；结束时落回网格

## 卡点语法（143.5 BPM，一拍 0.418 秒，一小节 1.672 秒）
| 鼓点 / 事件 | 画面 |
|---|---|
| 底鼓 | 字号冲击 1.04→1.0（主歌轻、副歌重） |
| 军鼓 | 反色闪一帧或局部反色 |
| 段落第一拍 | 清屏 / 重绘 / 换网格（终端式转场，不用淡入淡出） |
| 说唱逐字 | 歌词按 Whisper 字级时间戳逐字砸入，光标跟随 |
| 剪辑密度 | 主歌 1：2 小节一切 → 主歌 2：1 小节 → 主歌 3 快嘴：2 拍 → 英文说唱：1 拍 |
| 静默 | “冲破”前半拍、Bridge 2:53 鼓停 |

## 制作步骤
1. 资产：Codex 生成约 15–20 张灰阶剪影（各段场景）
2. 引擎：`render(t)` 纯函数（字符网格 Canvas2D + three.js 3D 字符粒子层），时间轴来自 `audio/beats.json` 和 `audio/asr.json`
3. **540p 样片**（横版 + 竖版各一段，含 0:39 冲破 → 1:26 副歌 1 结束）→ **停下来给你看**
4. 确认后渲染全片两个版本 → 混音（原曲 + 少量合成音效）→ 响度 → 自检 → 交付到 `成片/`
